# Neural-Genetic-Simulation
A neural network and genetic algorithm simulation built from scratch in Python with Pygame, where agents evolve over generations to avoid obstacles and navigate environments

## 🚀 Features
- **Built from Scratch:** No external machine learning heavy frameworks (like TensorFlow or PyTorch); the neural network and genetic algorithm logic are coded purely in Python.
- **Genetic Evolution:** Agents mutate, adapt, and evolve over successive generations to optimize performance.
- **Interactive Visualization:** Real-time rendering using Pygame to visualize agent behavior, inputs, and environment mapping.

## 🛠️ Tech Stack
- **Language:** Python
- **Library:** Pygame
- **Concepts:** Artificial Intelligence, Neural Networks, Genetic Algorithms, Vector Mathematics
